## Attendance Management Module


The Attendance module manages employee attendance tracking with enterprise-level business rules.


### Features

- Employee Check-In
- Employee Check-Out
- Daily Attendance Tracking
- Monthly Attendance Reports
- Attendance History
- Attendance Dashboard
- Attendance Analytics
- Excel/PDF/CSV Reports
- Attendance Validation Rules


### Business Rules

- One attendance record per employee per day
- Check-out must happen after check-in
- Future attendance dates are not allowed
- Attendance cannot be modified after payroll generation


### APIs

- Check-In API
- Check-Out API
- Attendance History API
- Attendance Summary API
- HR Attendance Management APIs
- Attendance Reports API
- Analytics APIs
